Diagnostic Tracker — Dual-GCN

Reads a student's pass/fail/time history and predicts mastery of all 25 concepts, propagated across the prerequisite graph. Proposal target: AUC > 0.80.

The 0.795 ceiling is the maximum AUC any model can reach on this dataset — an oracle that knows each student's true simulated traits still can't exceed it, because the label noise (slip/guess) is baked into the data-generating process itself.

Reading it: 0.7363 sits at 92.7% of that ceiling — the model is close to optimal on this data, not underperforming a fixable target. Cold-start (steps 1-2) is structurally near chance because h_t=0 for every student until they've answered something.

Best checkpoint: epoch 5 of 25, selected automatically by validation AUC (val AUC declined afterward — a mild overfit the checkpointing caught).

Honest read: PPO ties the naive baseline on success rate but isn't yet more efficient — when it succeeds, it takes longer. The diagnostic capability (below) is real; the efficiency edge over linear sequencing is still a work in progress.

Debugging journey — three distinct failure modes, found and fixed

  • Run 1
    Collapsed to 1 conceptReward gave no penalty for repeating an already-saturated concept — fixed with an explicit saturation-based repeat penalty.
  • Run 2
    Exploited an "unlock bonus"A reward meant to encourage progression instead over-rewarded high-fan-out concepts regardless of follow-through — removed in favor of the simpler repeat penalty.
  • Run 3
    Misdiagnosed as collapsedEvaluating with deterministic=True repeated a mildly-favored action 150 times, looking like collapse when the real policy was still near-uniform. Fixed the evaluation method itself.
  • Run 4
    Entropy annealingDecayed the exploration coefficient across training — success rate moved from 9% to 12%, current state.
